# rimworld-media

Images for the Steam Workshop pages of Evyatar108's RimWorld mods: description header bars, feature cards and banners.
GitHub Pages serves this repository at `https://evyatar108.github.io/rimworld-media/`, so a page links an image as
`[img]https://evyatar108.github.io/rimworld-media/<mod>/<file>.png[/img]`.

- One folder per mod (`vm2/` for Variety Matters 2).
- Only finished page images live here. Sources, scripts and shot lists stay in each mod's own repository
  (for VM2: `design\workshop\`).
- A file that a published page links must not be renamed or deleted; publish a new name instead.
- Each image is under 1 MB and about 800 px wide (Steam shrinks wider ones to the description column).

Images are © Evyatar108, made for these mod pages.
